Hide individual placed furnishings during GPose so you can stage and resize replacements with Brio.

- Search furnishings by name and locate a selected instance with an on-screen marker.
- Hide or restore individual furnishings, or restore all at once.
- Restore tracked furnishings when GPose ends or the plugin unloads.
- Copy an item's name and coordinates to help position its replacement in Brio.

Install **Furniture Veil** through [Rude's Dalamud plugin repository](https://github.com/rude-jerk/dalamud-plugins), then use `/fveil` in GPose. `/fveil restore` restores all tracked furnishings.

Built for Dalamud API 15 and .NET 10. Release compilation passes with zero warnings/errors, and all 14 lifecycle tests pass. Live game rendering has not yet been tested; furnishings with separate lights or effects may need additional handling. Replacement spawning and scaling are performed manually in Brio.
